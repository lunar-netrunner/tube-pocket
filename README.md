# Tube Pocket

Lecteur vidéo pour Windows avec une fenêtre flottante *Picture-in-Picture* : la vidéo reste au-dessus des autres fenêtres, avec de gros boutons utilisables au doigt, à la souris ou à la manette.

## Télécharger

Dans la page **Releases** (colonne de droite) :

| Fichier | Usage |
| --- | --- |
| `Tube-Pocket-Setup-0.1.8.exe` | Installeur. Recommandé : l'application démarre ensuite en une seconde. |
| `Tube-Pocket-Portable-0.1.8.exe` | Sans installation, double-clic. Démarrage plus lent (5 à 7 s). |

L'exe n'est pas signé : au premier lancement, Windows affiche « Informations supplémentaires → Exécuter quand même ».

## Commandes de la fenêtre flottante

- Tactile : pincer au milieu de la vidéo pour agrandir ou réduire, tirer la vidéo pour déplacer la fenêtre.
- Manette : croix ou stick gauche pour choisir une vidéo (A l'ouvre, B annule ou revient en arrière), stick droit pour faire défiler. Pendant la lecture : A lecture/pause, B fermer la fenêtre flottante, X/Y vidéo suivante/précédente, LB/RB −10 s / +10 s.
